# Code of Conduct

## Standard

Uczestnicy projektu powinni zachowywać się profesjonalnie, rzeczowo i z szacunkiem.
Nie akceptujemy nękania, dyskryminacji, gróźb, publikowania cudzych danych ani celowego
zakłócania pracy projektu.

## Egzekwowanie

Naruszenia można zgłaszać prywatnie maintainerom projektu. Zgłoszenia będą rozpatrywane
bez odwetu, z zachowaniem poufności w zakresie wymaganym przez sytuację.
